# Custos: releases

Este repositório guarda só os binários públicos do app Custos. O código-fonte não fica aqui.

Baixe o APK mais recente para Android:

https://github.com/alexfgregio/custos-releases/releases/latest/download/custos.apk

As notas de cada release trazem o SHA-256 do arquivo. O APK é só para celulares `arm64-v8a`.
